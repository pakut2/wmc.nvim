1. Wrist May Cry                                      *wmc.nvim-wrist-may-cry*

Vim is all about making text editing as efficient and ergonomic as possible.
But what if it was optimal not to always edit optimally? WMC is a Neovim plugin
that encourages variety in used motions through _Devil May Cry_-inspired style
ranks.

CONFIGURATION                           *wmc.nvim-wrist-may-cry-configuration*


  [!NOTE] Calling the `setup` function is optional.

DEFAULT SETTINGS ~

>lua
    require("wmc").setup({
        enabled = true,
        ui = {
            anchor = "NE",
            row = 1,
            col = function()
                return vim.o.columns - 5
            end,
            zindex = 50,
            border = "none",
        },
        logger = {
            enabled = false,
            log_file_path = vim.fn.stdpath("data") .. "/wmc.log",
        },
    })
<

  -----------------------------------------------------------------------
  Option                              Explanation
  ----------------------------------- -----------------------------------
  enabled                             Toggle wmc

  ui                                  Configure style rank display window
                                      (partially derived from
                                      vim.api.keyset.win_config). row and
                                      col support passing a function for
                                      dynamic Neovim window resize
                                      handling

  logger                              Toggle debug logging and change log
                                      destination
  -----------------------------------------------------------------------

RUNNING TESTS ~

Tests are executed with Neovim as the Lua interpreter with busted
<https://lunarmodules.github.io/busted>.


INSTALL TEST DEPENDENCIES

>shell
    luarocks install --tree lua_modules --lua-version 5.1 nlua
    luarocks install --tree lua_modules --lua-version 5.1 busted
<


RUN TESTS

>shell
    eval "$(luarocks path --tree lua_modules --lua-version 5.1)"
    luarocks test --lua-version 5.1
